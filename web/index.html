Joy-Con 2 Motion Web Game Platform

A reusable motion base: Joy-Con 2 → BLE → Adapter → Motion Engine → unified Motion API → games. Runs entirely off-console. Without a Joy-Con 2 it falls back to Mock IMU / Keyboard / Gamepad / Joy-Con 1.

Motion Playground → Live gyro / accel scope, motion speed, gesture readout, and the 3D Sword pipeline check. Motion Fruit Slash → The first full motion demo. Swing to slice fruit, avoid bombs. No game over. Input Test → Every button and both sticks of the left and right Joy-Con 2, press/release log, guided acceptance run.

Start-up

  1. Run the adapter: python -m adapter.src.service --source joycon2 (or --source synthetic with no hardware).
  2. Open a page above, pick a provider, press Connect.
  3. Calibration: hold the Joy-Con flat for 2 s → Calibration Complete.
  4. Play.

The Joy-Con 2 BLE link (left + right) is verified on hardware on macOS; per-item status is in docs/JOYCON2_PROTOCOL.md §J. Buttons and sticks work as soon as a controller is connected — the IMU calibration only matters for motion.
